MSc AI thesis (Utrecht University), topic scouting for **machine learning applied to the stock market and listed companies**, restricted to **2026 literature**. Supervisor: Dr. Ioana Karnstedt-Hulpuș. Work branch: `scouting-ml-stock-2026`.

| File | What it is |
|---|---|
| `ml_stock_topics_2026.md` | **Main deliverable**: morning summary, 18 raw ideas with kill tests, 6 full proposal cards (scored), runners-up |
| `lit_review_ml_stock_2026.md` | 2026 landscape across 12 areas (A1–A12), crowding map and gap list at the top |
| `references.bib` | All cited works; `note` field gives verification status |
| `NOTES.md` | Decision log: taxonomy, access tests, every search query, rejected ideas, status |

Verification legend: `[FT]` full text · `[ABS]` abstract page opened · `[ABS-s]` abstract seen in a search result · `[UNVERIFIED]` · `[BACKGROUND]` pre-2026 dataset/library/method origin.
